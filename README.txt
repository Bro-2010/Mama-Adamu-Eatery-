# Mama Adamu Eatery — Digital Menu

## Files
- index.html — main menu page
- style.css — design
- menu.js — menu items, prices, categories and WhatsApp number

## IMPORTANT BEFORE DEPLOYING
Open `menu.js` and change:
1. `WHATSAPP_NUMBER` to Mama Adamu's real WhatsApp number (country code 233, no + or spaces).
2. Replace/add menu items in `menuItems`.
3. Replace sample image URLs if you have the client's real food photos.
4. Update the location in `index.html` if needed.
5. Update the call link in `index.html`.

## How it works
Customers open the website, search/browse the menu, add items to an order, then tap "Send Order on WhatsApp". The website creates the order message automatically.

## Deployment
Upload all three files to GitHub Pages, Netlify, or another static hosting service. Keep the three files in the same folder.

## Note
The sample menu/prices and sample images are placeholders. Confirm all real prices, contact details and photos with the client before publishing.
